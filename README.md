# Fonts

`NotoNastaliqUrdu.ttf` is the Noto Nastaliq Urdu font by the Noto Project Authors,
used for all Urdu text in the booklet. It is licensed under the SIL Open Font
License 1.1 (see `OFL.txt`), which allows it to be included here.

Source: https://github.com/notofonts/nastaliq

Code examples use DejaVu Sans Mono and English text uses Arial or Liberation Sans,
which are available on most computers. If they are missing, a similar font is
used automatically.
